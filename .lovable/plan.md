

## План: Контрольная по физике для 7 класса — «Механическая работа и Мощность»

### Структура — 11 вопросов

**Часть 1. Теория (5, Textarea + FileAttach)**:
1. Два условия совершения механической работы
2. Формула работы (F·s) + единицы измерения
3. Мощность — что характеризует + формула
4. Единица мощности в СИ + в честь кого названа
5. Рюкзак в горизонтальном коридоре — почему работа = 0

**Часть 2. Задачи (6, Textarea + FileAttach)**:
1. Глубина колодца (m=10 кг, A=650 Дж)
2. Подъёмный кран (m=5 т, h=8 м)
3. Мощность лифта (m=300 кг, h=12 м, t=30 с)
4. Работа мясорубки (P=800 Вт, t=20 мин)
5. Трамвай «Витязь-М» (P=450 кВт, t=3 ч)
6. ⭐ Эксперт: санки под углом 60° (F=100 Н, s=40 м, cos=0,5)

Шапка: «Проверочная работа по физике (7 класс). Тема: Механическая работа и Мощность.» Напоминание про СИ и g=10 Н/кг. Защита `user-select: none` на текстах.
