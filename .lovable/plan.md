

## План: Индивидуальное время на каждый квиз-вопрос

Сейчас у `Quiz` один `secondsPerQuestion` на все вопросы. Сделаем опциональное поле `seconds` у каждого `QuizQuestion` — если задано, используется оно; иначе fallback на общий `secondsPerQuestion`.

### Изменения в `Quiz.tsx`
- В интерфейс `QuizQuestion` добавить `seconds?: number`.
- В таймере брать `q.seconds ?? secondsPerQuestion` для текущего вопроса (и для прогресс-бара, и для тика, и для расчёта `timeSpent`).
- `QuizIntro` — показывать диапазон, например «от 20 до 60 сек на вопрос», если времена разные.
