

## План: Фильтрация предметов по выбранному классу

### Проблема
Сейчас выпадающий список предметов показывает все 3 варианта (Информатика, Физика, Технология) для любого класса. Дети выбирают 7 класс, но не видят, какой предмет им доступен, а при выборе недоступного получают ошибку "Тест недоступен". Это путает.

### Решение
Фильтровать список предметов в `<SelectContent>` на основе `AVAILABLE_TESTS[grade]`. Показывать только доступные предметы для выбранного класса. Сбрасывать `subject` при смене `grade`.

### Изменения в `src/pages/Index.tsx`

1. **Маппинг ключей → лейблов** (новая константа):
```ts
const SUBJECT_LABELS: Record<string, string> = {
  informatics: "Информатика",
  physics: "Физика",
  technology: "Технология",
};
```

2. **Сброс предмета при смене класса**: в `onValueChange` селекта класса добавить `setSubject("")`.

3. **Фильтрация предметов**: вместо захардкоженных `<SelectItem>` — динамический рендер из `AVAILABLE_TESTS[grade]`:
```tsx
{(AVAILABLE_TESTS[grade] || []).map(s => (
  <SelectItem key={s} value={s}>{SUBJECT_LABELS[s]}</SelectItem>
))}
```

4. **Блокировка селекта предмета** если класс не выбран (`disabled={!grade}`).

### Ошибки сборки
Ошибки `@swc/core native binding` — это инфраструктурная проблема среды сборки, не связанная с кодом. Они решатся автоматически при повторной сборке.
