
План: сгенерировать новый случайный `TEACHER_JWT_SECRET` (64-символьная hex-строка, криптостойкая) и запросить у пользователя его установку через add_secret. После установки — пользователя один раз выкинет из админки, надо будет перезайти логином+паролем, дальше всё стабильно.

Шаги:
1. В default mode сгенерирую случайную строку (например через `openssl rand -hex 32` или Node `crypto.randomBytes`).
2. Покажу её в чате.
3. Вызову `add_secret` для `TEACHER_JWT_SECRET` с этой строкой — пользователь скопирует и вставит в поле.
4. Напомню: после сохранения нужно открыть `/admin`, заново ввести `TEACHER_LOGIN` + `TEACHER_PASSWORD`. Старый токен в `sessionStorage` отвалится автоматически (мы добавили авто-логаут на 401 в прошлый раз).

- Не меняю код функций — они уже корректно читают `TEACHER_JWT_SECRET`.
- Не правлю TTL токена (8ч) — это отдельная задача, спрошу отдельно если захочешь.
