

## План: Запретить вставку в Textarea кода Python

Да, возможно. Блокируем `paste`, `drop` и `contextmenu` (правый клик → Вставить) на Textarea задания «Генератор героя».

### Реализация

В `Grade8InformaticsPython.tsx` на главной Textarea с кодом добавить:
- `onPaste={(e) => e.preventDefault()}` + toast «Вставка запрещена — пиши код сам»
- `onDrop={(e) => e.preventDefault()}`
- `onContextMenu={(e) => e.preventDefault()}` (блок правого клика)
- `autoComplete="off"`, `spellCheck={false}`

Дополнительно: при попытке вставки логировать событие в систему анти-чита (как copy-attempt) — отправлять в Telegram алерт с именем ученика, чтобы учитель видел попытки. Используем существующий механизм из `notify-copy-attempt` edge function.

### Опционально (на твой выбор — скажи, нужно ли)
- Распространить тот же запрет на **все** Textarea во всех контрольных (физика 7/9, информатика 7/9, технология) — одной правкой через общий компонент-обёртку `NoPasteTextarea`.
- Блокировать также `Ctrl+V` / `Cmd+V` на уровне `onKeyDown` (двойная защита, на случай экзотики).

### Ограничения (честно)
- Защита работает против обычной вставки, но продвинутый ученик может открыть DevTools и вставить через JS. Полностью защититься в браузере нельзя — но 99% школьников такое не сделают, а попытка открыть DevTools уже логируется анти-читом.
