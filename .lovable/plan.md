## Задача

Подготовка к итоговой к/р за 4 четверть для 6 класса. Сейчас — **только** добавить 6 класс в селектор класса на главной, чтобы дети могли войти и через код live-сессии, и (на будущее) через прямой выбор предмета.

## Что меняется

### `src/pages/Index.tsx`

В константе `AVAILABLE_TESTS` добавить ключ `"6"` со списком предметов:

```ts
const AVAILABLE_TESTS: Record<string, string[]> = {
  "6": ["informatics", "technology", "physics"],
  "7": [...],
  "8": [...],
  "9": [...],
};
```

После этого:
- На главной появится кнопка **«6 класс»** (рендерится автоматически из `AVAILABLE_TESTS`).
- Выбор предмета работает (используются те же лейблы из `SUBJECT_LABELS`).
- На шаге «Выберите работу» покажется «Работы пока не добавлены» (это уже корректно обрабатывается в `test-pick`), потому что в `TESTS_CATALOG` нет статичных тестов для 6 класса. Это ожидаемо — итоговая работа будет создаваться учителем как live-сессия.
- Дети 6 класса будут заходить **через «🎟 Войти по коду класса»** на главной — этот путь не зависит от класса вообще.

## Что НЕ делаем сейчас

- Сам контент итоговой к/р для 6 класса (компоненты `Grade6*`) — будем делать отдельно, когда ты дашь задания.
- Изменения в `TESTS_CATALOG` — пусто, т.к. итоговая будет live.
- Никаких миграций БД.
