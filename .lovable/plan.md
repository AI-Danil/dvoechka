

## План: Новый поток выбора + вторая контрольная по физике для 8 класса

### Изменения UX (новый flow)

Сейчас на одном экране сразу всё (имя + класс + предмет). Делаем 4 шага:

1. **Шаг 1 — Класс** (`step: "grade"`)
2. **Шаг 2 — Предмет** (`step: "subject"`) — фильтруется по классу
3. **Шаг 3 — Имя и Фамилия** (`step: "name"`)
4. **Шаг 4 — Выбор работы** (`step: "test-pick"`) — список доступных контрольных по выбранному предмету
5. После выбора → переход на экран теста

В `Index.tsx`: заменить `Screen = "login" | "test" | "success"` на `Screen = "login" | "test" | "success"` где `"login"` теперь содержит внутренний `loginStep`. Каждый шаг — отдельная карточка с кнопкой «Назад» и «Далее».

Новый state `testId: string` — определяет, какой компонент рендерить.

### Новый компонент `Grade8PhysicsPower.tsx`

6 расчётных задач (все Textarea + FileAttach):
1. Работа тока (U=24В, I=2А, t=5 мин)
2. Паяльник (P=120Вт, U=220В) → I, R
3. Кол-во теплоты (R=100Ом, I=2А, t=15 мин)
4. Электроплитка (I=5А, U=120В, t=5ч, тариф 5 р/кВт·ч)
5. Спираль утюга (P=1кВт, S=0.1мм², U=220В, ρ=1.1) → длина
6. Укороченная спираль (P=1.5кВт, укоротили на ⅓) → новая мощность

Шапка: «Контрольная по физике (8 класс). Тема: Работа и мощность электрического тока. Закон Джоуля—Ленца. Нагревательные приборы.»

Защита от копирования (`user-select: none` на текстах задач) — как везде.
