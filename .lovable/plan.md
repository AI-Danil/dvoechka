

## План: UX-улучшения + редизайн цветовой схемы

### 1. Цветовая схема — зеленые акценты

**Светлая тема (`:root`):**
- `--primary`: темно-зеленый (~`145 60% 32%`)
- `--accent`: темно-зеленый (~`145 63% 35%`)
- `--ring`: зеленый
- Фон остается светлым (`150 10% 96%`)

**Темная тема (`.dark`):**
- `--primary`: светло-зеленый (~`145 60% 55%`)
- `--accent`: светло-зеленый (~`145 63% 50%`)

Файл: `src/index.css`

### 2. Валидация имени — два русских слова

В `handleStart` добавить проверку regex: `/^[А-ЯЁа-яё]+\s+[А-ЯЁа-яё]+$/` — ровно два слова, только кириллица, без цифр и спецсимволов. Toast с ошибкой при несоответствии.

Файл: `src/pages/Index.tsx`

### 3. Модальное подтверждение перед отправкой

Добавить `AlertDialog` из shadcn/ui. По нажатию "Завершить" открывается диалог: "Вы уверены? Это действие нельзя отменить. После отправки вернуться к тесту будет невозможно." Кнопки: "Отмена" / "Отправить".

Файл: `src/pages/Index.tsx`

### 4. Прогресс-бар

Визуальная полоса в шапке теста, показывающая `answeredCount / totalCount`. Считать заполненные (непустые) ответы для текущего класса.

Файл: `src/pages/Index.tsx`

### 5. Автосохранение в localStorage

- При каждом изменении ответа сохранять в `localStorage` по ключу `test_draft_${grade}_${subject}`
- При загрузке теста — восстанавливать из localStorage
- После успешной отправки — очищать localStorage
- Добавить пометку "Ответы автоматически сохраняются" под прогресс-баром

Файл: `src/pages/Index.tsx`

### 6. Предупреждение за 5 минут

Когда `timeLeft === 300`, показать заметный toast/alert: "До конца теста осталось 5 минут!". Уже есть авто-отправка по таймеру.

Файл: `src/pages/Index.tsx`

### 7. Запрет повторной сдачи

Записать в `localStorage` ключ `test_submitted_${grade}_${subject}_${studentName}` после успешной отправки. При попытке начать тест — проверить и заблокировать с сообщением "Вы уже прошли этот тест".

Файл: `src/pages/Index.tsx`

### 8. Античит в конец Telegram-сообщения

Переместить блок античита (строки 86–93) после блоков вопросов (после строки 158).

Файл: `supabase/functions/send-test-results/index.ts`
