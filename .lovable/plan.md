

## Убрать отдельное поле попытки — спрятать в поле имени

### Идея
Вместо отдельного Input для попытки — парсить третье слово из поля имени как номер попытки. Ученик вводит "Иван Иванов", а если учитель скажет — "Иван Иванов 2".

### Изменения в `src/pages/Index.tsx`:

1. **Убрать отдельный Input для попытки** (строки 396-404) и state `attempt`
2. **Изменить валидацию имени** — regex принимает два русских слова + опционально число: `/^[А-ЯЁа-яё]+\s+[А-ЯЁа-яё]+(?:\s+(\d+))?$/`
3. **В `handleStart`** — парсить имя:
   - Извлечь попытку из третьего слова (если есть цифра)
   - Сохранить чистое имя (без номера попытки) в `studentName`
   - Установить `attempt` из распарсенного значения или "1"
4. **Подсказка под полем** остаётся "Два слова на русском" — ученик не узнает про третье слово
