

## Скрытый номер попытки

### Идея
Добавить скрытое поле "попытка" (по умолчанию 1). Ученик его не видит. Учитель говорит ученику устно: "введи попытку 2". Ключ повторной сдачи в localStorage будет включать номер попытки, что позволит пересдавать без очистки данных.

### Реализация

**`src/pages/Index.tsx`:**
- Добавить state `attempt` (строка, по умолчанию `"1"`)
- На экране логина добавить невидимое (скрытое) поле ввода попытки. Варианты:
  - Маленький неприметный Input внизу формы с placeholder "1", без label — ученик не обратит внимания, но учитель скажет "поменяй на 2"
  - Или: поле появляется только по тройному клику на заголовок
- Включить `attempt` в ключ `getSubmittedKey`: `test_submitted_${grade}_${subject}_${name}_${attempt}`
- Включить `attempt` в ключ `getDraftKey`: `test_draft_${grade}_${subject}_${attempt}`
- Передать `attempt` в payload при отправке

**`supabase/functions/send-test-results/index.ts`:**
- Принять `attempt` из body
- Добавить в заголовок сообщения: `🔄 Попытка: ${attempt}` (только если > 1)

### Файлы
- `src/pages/Index.tsx` — скрытое поле + логика ключей
- `supabase/functions/send-test-results/index.ts` — номер попытки в TG
