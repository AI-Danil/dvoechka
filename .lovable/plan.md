
## Починка видимости тестов для учеников

Причина найдена: список тестов для учеников ломается до запроса к опубликованным работам.

### Что происходит сейчас
В `src/lib/dbTests.ts` функция `loadPublishedTestsForGradeSubject()` сначала делает запросы к таблицам:
- `classes`
- `subjects`

Для учеников это анонимный доступ, а у этих таблиц сейчас нет публичного `SELECT`. Поэтому:
- запрос к `classes` возвращает пустой массив
- `classRow` не находится
- функция сразу делает `return []`
- в UI показывается только старый хардкод-тест из `TESTS_CATALOG`

Именно поэтому новый тест в БД есть, но дети его не видят.

---

## Что исправлю

### 1. Уберу зависимость ученического UI от закрытых таблиц
Перестрою student-flow так, чтобы он читал только публичные данные.

Лучший вариант:
- пересоздам `public_tests` так, чтобы view сразу содержал:
  - `id`
  - `title`
  - `kind`
  - `time_per_question_sec`
  - `class_id`
  - `class_name`
  - `class_year`
  - `subject_id`
  - `subject_name`
  - `created_at`

Тогда фронт сможет фильтровать тесты напрямую по:
- `class_year = 2025`
- `class_name` начинается с `"9"` / `"8"` / `"7"`
- `subject_name = "Технология"` и т.д.

Это безопасно: здесь нет чувствительных данных, только справочники для отображения.

### 2. Обновлю `src/lib/dbTests.ts`
Перепишу `loadPublishedTestsForGradeSubject()` так, чтобы она:
- больше не обращалась к `classes` и `subjects`
- читала только `public_tests`
- фильтровала тесты по публичным полям из view

Итог: для ученика останется один публичный запрос вместо трёх.

### 3. Оставлю `public_test_questions` как есть
Там уже правильный публичный слой без `correct_index` и `expected_answer`, так что для вопросов менять логику не нужно.

### 4. Проверю экран выбора теста
В `src/pages/Index.tsx` логика списка уже правильная:
- хардкод-тесты из `TESTS_CATALOG`
- плюс `dbTests.map(...)`

После исправления загрузчика там автоматически появится второй пункт:
- `Итоговая контрольная (3 четверть)`
- `Самостоятельная: Поиск, адресация и логика в Интернете (21.04.2026)`

### 5. Небольшой UI-штрих
Заодно поправлю бейдж для `hybrid`, чтобы вместо общего текста
`Самостоятельная от учителя`
показывалось что-то вроде:
`Смешанный тест от учителя`

## Файлы и изменения

- пересоздать `public.public_tests` с join на `classes` и `subjects`

### Фронт
- `src/lib/dbTests.ts`
  - убрать запросы к `classes` и `subjects`
  - перейти на фильтрацию через `public_tests`
- `src/pages/Index.tsx`
  - при желании только текст бейджа для `hybrid`

## Технические детали
```text
Текущее узкое место:
student UI -> classes (anon) -> [] -> no classRow -> return []

После исправления:
student UI -> public_tests (anon) -> filter by class_name/class_year/subject_name -> show test
```

```text
Почему не делаю публичный SELECT на base tables:
- это лишнее расширение доступа
- view уже используется как безопасный публичный слой
- правильнее расширить public_tests, чем открывать classes/subjects напрямую
```
