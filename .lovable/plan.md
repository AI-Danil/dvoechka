

## Итоговая контрольная за третью четверть

### Экран 1: Главная / Вход
- Заголовок "Итоговая аттестация за 3-ю четверть"
- Поле ввода имени и фамилии
- Выпадающий список класса (5–9) и предмета (информатика, физика, технология)
- Кнопка "Начать тестирование" (валидация: имя ≥ 3 символов)
- При выборе комбинации, отличной от "8 класс + информатика", показываем заглушку "Тест пока недоступен"

### Экран 2: Тестирование (8 класс, информатика)
- Sticky-таймер на 40 минут с обратным отсчётом; по истечении — автоотправка
- **Блиц-опрос** (7 вопросов, grid 2 колонки на ПК, 1 на мобильных) — input-поля
- **Часть 1: Информатика** — 3 задачи (textarea/input)
- **Часть 2: Технология / Python** — 3 задачи (textarea с monospace-шрифтом)
- Зелёная кнопка "Завершить работу и отправить ответы"

### Экран 3: Успешное завершение
- "✅ Работа успешно сдана!" с сообщением о закрытии вкладки

### Скрытый античит-мониторинг
- Во время теста молча собирает события: blur, visibilitychange, copy, paste, PrintScreen, Meta, contextmenu
- Логирует в массив с таймстампами — отправляется вместе с ответами

### Telegram-интеграция (через Supabase Edge Function)
- Edge Function `send-test-results`: принимает JSON с ответами, именем, логом античита
- Отправляет форматированное сообщение в Telegram через Bot API (токен и chat_id хранятся как серверные секреты)
- Фронтенд вызывает функцию при завершении теста

### Дизайн
- Минималистичный академический стиль: светло-серый фон, белые карточки, синие/зелёные акцентные кнопки
- Адаптивная вёрстка (мобильные + десктоп)
