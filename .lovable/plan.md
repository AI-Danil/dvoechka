

## Топ-2 самых выгодных по соотношению «эффект / токены»

Из всего, что я предлагал, реально окупаются два пункта. Остальное — либо дорого, либо обходится школьником с Google за 5 минут.

### 1. Блокировка F12 / Ctrl+Shift+I / Ctrl+U / ПКМ + алерт в Telegram
**Почему выгодно:** ~10 минут работы, ловит 90% любопытных школьников. Большинство даже не знают, что DevTools можно открыть через меню браузера — для них F12 это и есть «единственный способ». Бонус: каждое нажатие F12 → алерт в TG «Иван пытался открыть DevTools» (с тем же 10-секундным дебаунсом, что уже есть).

**Что делаю:**
- Глобальный `keydown` listener на страницах с заданием: блок F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S.
- Глобальный `contextmenu` блок на странице теста (ПКМ отключён везде, не только в Textarea).
- Переиспользую существующий хук дебаунса (вынесу из `Grade8InformaticsPython` в `src/hooks/useAntiCheatNotify.ts`), чтобы алерты «открыл DevTools» тоже не флудили.

### 2. Лимиты + whitelist в `FileAttach.tsx`
**Почему выгодно:** ~10 минут, закрывает реальную дыру. Сейчас можно залить 500 МБ видео как «решение задачи» и засрать твой `test-attachments` bucket за один сабмит. Это не теория — это первое, что попробует «умный» школьник, когда устанет от Ctrl+V.

**Что делаю:**
- Макс размер: **5 МБ** на файл. Больше — toast «Файл слишком большой» + блок.
- Whitelist MIME: только `image/*`, `application/pdf`, `text/plain`. Всё остальное — отбой.
- Проверка чисто на клиенте (для серверной нужен rate-limit/Zod на edge function — это уже следующий уровень, в рамках «выгодного минимума» не делаю).

### Что НЕ беру (и почему)
- **Капча Turnstile** — эффективна, но требует регистрации на Cloudflare + секрет + edge function правки. ~30 мин + внешний шаг от тебя. Не вписывается в «минимум токенов».
- **Детектор открытого DevTools через `console.log`/`getter`** — хрупко, ломается при обновлениях браузера, легко обходится.
- **MutationObserver на Textarea** — сложно, ловит редкий кейс (программная вставка через консоль), большинство школьников до этого не дойдёт.
- **Серверный rate limit** — у Lovable Cloud нет нормальных примитивов под это, реализация ad-hoc.

### Файлы

| Действие | Файл |
|----------|------|
| Создать | `src/hooks/useAntiCheatNotify.ts` (вынос дебаунса + общая `notify`-функция) |
| Создать | `src/hooks/useDevToolsBlock.ts` (глобальные keydown/contextmenu блокировки + алерт) |
| Изменить | `src/components/tests/Grade8InformaticsPython.tsx` (перейти на новый хук) |
| Изменить | `src/pages/Index.tsx` (подключить `useDevToolsBlock` на экране теста) |
| Изменить | `src/components/FileAttach.tsx` (лимит 5 МБ + MIME whitelist) |

### Эффект
- 90% школьников упрутся в заблокированный F12 и сдадутся.
- Каждая попытка открыть DevTools → алерт в TG (с дебаунсом).
- Никто не зальёт мусорный 500 МБ файл в storage.
- Время на реализацию: ~25 минут. Никаких внешних регистраций.
