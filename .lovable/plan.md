
## План диагностики (read-only, без правок)

1. Дёрнуть `list-results` напрямую через curl с твоим текущим teacher token — увидеть, возвращает ли она 30+ записей или пустой массив / 401.
2. Посмотреть HTTP-логи edge (`function_edge_logs`) — какие были вызовы list-results за последний час, какой статус-код.
3. Прочитать текущий `src/pages/Admin.tsx` после правок с realtime — убедиться, что `load()` не падает молча в catch и что `rows` реально присваивается.
4. Прочитать `supabase/functions/list-results/index.ts` — проверить, нет ли там фильтра по дате/лимиту, который мог отрезать старые записи.

После диагностики — точечный фикс (скорее всего одно из трёх):
- протух teacher token → добавить авто-логаут при 401,
- realtime-подписка кидает исключение и ломает state → обернуть в try/catch,
- edge function режет выдачу лимитом → убрать лимит или поднять.

Никаких догадочных правок до того, как увижу что именно отвечает list-results.
